# LinkedIn banner: Klearway

**Artwork:** `docs/brand/linkedin-banner-1584x396.png` (PNG, 1584 × 396). The vector source is `docs/brand/linkedin-banner-1584x396.svg`. To regenerate it, run `npm run assets`.

## Layout

| Zone | Content |
|---|---|
| 0–400 px (left) | Empty dark field. On desktop, the company logo overlaps the lower-left of the banner, so nothing important sits here. |
| 440–1090 px (centre) | Logo mark and wordmark, then the headline "Catch the document mismatch / before it holds up the shipment." in paper and signal amber, then a mono line: DOCUMENT CHECKS · SHIPMENT STATUS · IMPORTER UPDATES |
| 1128–1528 px (right) | A product fragment: a check-results card showing one mismatch and two passes, labelled SAMPLE DATA |

- **Mobile crop:** LinkedIn's mobile app crops the sides. The headline sits in the central band, so it stays visible; the product card is decorative and may be partly cropped.
- **Colours:** Ink `#0F1D1C` background with a 7% paper dot grid; Paper `#F5F1E8`; Signal `#E9A23B`; Tide `#1E6B5A`; Flag `#B8402A`.
- **Type:** IBM Plex Sans 600 for the headline, IBM Plex Mono 500 for labels. Text is converted to vector paths, so it renders the same everywhere.
- **Truthfulness:** the card uses sample data and says so on the banner. No customer logos, metrics or claims appear.
